# Open Source Funding

Open source funding is the set of economic mechanisms used to sustain maintainers and shared software infrastructure whose benefits are widely distributed but whose maintenance costs are concentrated among relatively few contributors.

## Notes

Voluntary donations, sponsorships, support contracts, foundations, procurement rules, and dependency-based levies distribute costs differently. The core collective-action problem is that software can be copied at negligible marginal cost while security work, review, releases, and incident response require continuing labor.
