# Token Relay Fraud

Token relay fraud is an abuse pattern where tokens, sessions, or access credentials are resold, proxied, or relayed so unauthorized users can consume services, evade controls, or launder activity through someone else's access.

- [2026-07-26: Evening Brief — Sunday, July 26, 2026](../sources/newsletter-2026-07-26-evening.md) — The Vectoral item on token relay markets frames token resale as fraud infrastructure, not just account-sharing leakage.

## Notes

The concept connects API economics to security: if access is metered by tokens or sessions, black markets will try to turn those control points into transferable commodities.
